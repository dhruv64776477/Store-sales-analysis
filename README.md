
# Store Sales Data Analysis

## Project Overview
An exploratory data analysis project using Python
to investigate Store sales and profitability.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
[Superstore Dataset on Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final/data)

## Project Objectives
- Analyze overall sales and profit.
- Identify top-performing regions.
- Analyze product categories and subcategories.
- Understand customer purchasing behavior.
- Investigate the relationship between discounts and profit.
- Identify sales trends over time.

## How to Run
1. Clone this repository.
2. Create and activate a virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Download the dataset from Kaggle.
5. Place the CSV file in the `data/` folder.
6. Open the notebook and run the cells.
